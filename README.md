# Mi Inglés

Web personal para aprender inglés desde cero, optimizada para móvil.

## Abrir la app

Abre `index.html` en el navegador, o activa GitHub Pages en **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. Cuando la publicación haya terminado, la dirección prevista es https://luismgnictech-cloud.github.io/englishlearn/.

## Funciones actuales

- Diez lecciones iniciales con ejercicios de opción múltiple.
- Frases con pronunciación mediante la síntesis de voz del navegador, según disponibilidad del dispositivo.
- Progreso local en el navegador, sin sincronización.

## Pendiente

La conversación libre con IA por texto y voz aún no está conectada. No incluyas claves de servicios de IA en el repositorio público ni en `index.html`; usa un servidor que proteja las credenciales.
